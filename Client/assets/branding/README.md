# Branding Assets

Shared branding files for `superweb-client`.

- `superweb-cluster.png`: source logo artwork provided by the project
- `superweb-client.ico`: Windows icon generated from the source artwork

The WinUI3 frontend consumes these assets for:

- the executable icon
- the window icon
- the sidebar brand image
- portable publish output under `windows_native/winui3/dist/app/Assets/Branding/`
